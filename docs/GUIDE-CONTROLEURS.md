# Guide des contrôleurs

## Avant l'événement

1. Téléphone chargé (une batterie externe est conseillée), connexion Internet (4G ou Wi-Fi) vérifiée.
2. Ouvrez l'adresse communiquée par l'équipe (en **https://**), connectez-vous avec **votre** identifiant.
3. Astuce : dans le menu du navigateur, « Ajouter à l'écran d'accueil » crée une icône qui ouvre directement le contrôle.
4. Choisissez l'**événement contrôlé** en haut de l'écran (il reste mémorisé).

## Contrôler un billet

### Avec l'appareil photo (mode « Scanner le QR code »)

1. Appuyez sur **Activer la caméra** et **autorisez** l'accès quand le téléphone le demande.
2. Placez le QR code du billet (sur téléphone ou imprimé) dans le cadre : le contrôle est **automatique**.
3. Lisez le résultat qui s'affiche en plein écran (avec un son et une vibration).

Boutons utiles : **Changer de caméra**, **Lampe** (si le téléphone le permet), **Arrêter la caméra**.

### À la main (mode « Saisie manuelle »)

Si la caméra est refusée ou indisponible, ou si le QR code est abîmé ou illisible : touchez **Saisie manuelle**, tapez le code
imprimé sous le QR code (les espaces n'ont pas d'importance), puis **Vérifier le billet**.

## Lire le résultat

| Écran | Signification | Que faire |
|---|---|---|
| **VERT · Billet valide** | Premier passage de ce billet pour cet événement | Laisser entrer. L'écran se libère seul après 2 secondes |
| **ORANGE · Déjà utilisé** | Ce billet est déjà entré : l'heure et le contrôleur du premier passage s'affichent | Refuser. En cas de contestation, appeler un administrateur |
| **ROUGE · Billet invalide** | Code inconnu, mal recopié, ou QR code falsifié | Refuser. Si saisie manuelle : vérifier la recopie et réessayer |
| **ROUGE · Billet annulé** | Billet annulé par l'association | Refuser, orienter vers un administrateur |
| **ROUGE · Autre événement** | Billet valable pour un autre événement | Refuser, vérifier l'événement choisi en haut de l'écran |
| **GRIS · Erreur technique** | Le serveur n'a pas pu vérifier (réseau, panne) | **Ne pas laisser entrer** : réessayer ; si cela persiste, prévenir un administrateur |

**Règle d'or : on ne laisse entrer que sur un écran VERT.** Le fait que le QR code se lise ne prouve rien : seul le serveur
décide, et il refuse en cas de doute.

Les écrans de refus restent affichés jusqu'à ce que vous touchiez **Billet suivant** (ou la touche Entrée).

## Problèmes fréquents

| Problème | Solution |
|---|---|
| « Accès à la caméra refusé » | Réglages du téléphone > navigateur (Safari, Chrome) > Caméra > Autoriser, puis recharger la page. Sinon, saisie manuelle |
| La caméra ne s'ouvre pas du tout | Vérifier que l'adresse commence par https:// ; fermer les autres applications qui utilisent la caméra |
| Le QR code ne se lit pas | Augmenter la luminosité de l'écran du billet, éviter les reflets, reculer un peu, utiliser la lampe ; sinon saisie manuelle |
| « Session expirée » | Se reconnecter (la session expire après 4 h d'inactivité ou 14 h au total) |
| « Erreur technique » répétée | Vérifier la connexion Internet du téléphone ; prévenir un administrateur |

## Après l'événement

Touchez **Déconnexion** en haut de l'écran.
